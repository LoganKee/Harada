Backup & restore

Your data stays in this browser on this phone. Export a backup regularly; deleting browser data or opening the app in a different browser can erase or separate your progress.

Home screen installation

For a true installable offline app, open the hosted version in Safari (iPhone) or Chrome (Android), then choose Add to Home Screen / Install App. It doesn't need an App Store account or server database. A downloaded HTML file can also run locally, but installation and persistent storage for file:// pages vary by phone.

Privacy

No account, analytics, advertisements, or external API calls. Entries are stored locally. Exported backups contain your personal notes, so keep them private.
